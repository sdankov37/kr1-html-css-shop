# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница (с блоком FAQ);
- `catalog.html` — каталог товаров;
- `category.html` — страница категории «Электроника»;
- `product.html` — карточка товара (с блоком отзывов);
- `order.html` — оформление заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — скрипт для модального окна, валидации формы и кнопки «Наверх»;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS (Flexbox, Grid, БЭМ, CSS-переменные);
- JavaScript (базовый уровень);
- Git;
- GitHub.

## Самостоятельные доработки

1. **Блок отзывов** на странице товара — реализован через `<article>` и CSS Grid.
2. **Блок FAQ** на главной странице — реализован через нативные `<details>` и `<summary>` (работает без JavaScript).
3. **Изображения товаров** — вместо текстовых заглушек используются теги `<img>` с атрибутом `alt`.
4. **Дополнительная страница** — `category.html` с категорией товаров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header`, `site-nav`, `breadcrumbs`, `hero`, `section`;
- `products-grid`, `product-card`, `catalog-layout`, `catalog-filters`, `catalog-products`;
- `order-dialog`, `order-form`, `button`, `success-message`;
- `site-footer`, `aside-info`, `contacts-list`;
- `faq-list`, `faq-item` (новые);
- `reviews-list`, `review` (новые).

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`;
- БЭМ-именование классов без глубокой вложенности селекторов.
