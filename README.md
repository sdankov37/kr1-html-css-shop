# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — скрипт для модального окна, валидации формы и кнопки «Наверх»;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS;
- JavaScript (базовый уровень);
- Git;
- GitHub.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `catalog-products` — список товаров;
- `filters-form` — форма фильтров;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `success-message` — сообщение об успешной отправке;
- `site-footer` — подвал сайта;
- `aside-info` — дополнительный блок;
- `contacts-list` — список контактов.

Модификаторы:

- `site-nav__link--active` — активный пункт меню;
- `product-card--featured` — выделенная карточка;
- `product-card--discount` — карточка со скидкой;
- `button--primary` — основная кнопка;
- `button--secondary` — второстепенная кнопка;
- `button--disabled` — визуально отключённая кнопка.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`;
- плавная прокрутка `scroll-behavior: smooth`;
- подсветка цели якоря через `:target`;
- БЭМ-именование классов без глубокой вложенности селекторов.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для шапки и навигации;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.
